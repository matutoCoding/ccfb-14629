# 网箱双目测鱼系统(仿真版)

大黄鱼深水网箱双目立体视觉测鱼系统。浏览器内运行,TypeScript + WebGPU 渲染,数据存 IndexedDB。当前为仿真阶段:水下画面程序化生成,整条测量链路(标定 → 对应 → 三角测量 → 长重换算 → 生长分析)与真实系统一致,后续可将仿真图像源替换为真实相机帧。

## 运行

```bash
pnpm install
pnpm dev      # 开发
pnpm build    # 构建(含类型检查)
```

需要支持 WebGPU 的浏览器(最新 Chrome / Edge)。

## 页面

- **网箱档案**:按口建档(周长、网深、放苗日期、苗种、尾数),每口箱挂 1~4 台双目相机,记录基线、安装深度、圆周位置、朝向
- **相机标定**:水下棋盘格采集(9×6,格距 40mm),张正友法 + 联合光束法平差解内参/畸变/双目外参,逐张重投影误差,可剔除重算
- **双目画面**:实时仿真渲染(鱼群摆尾巡游、躲相机、浑浊度/光照随水深与时辰变化),手动两点/分段测量、NCC 极线自动对应、自动测量
- **测量记录**:明细 + 真值对账(每条误差、平均误差、系统偏性),叉长分布直方图,样本量不足提示
- **生长分析**:均重曲线、日增重、距上市天数、按存鱼量和水温的投喂建议
- **设置**:长重系数(分季节)、水温、投喂率表、参数扰动(故意给错看偏差)、数据管理

## 测量链路(与真值严格分离)

- 渲染用**真值参数**(含径向畸变、平面玻璃罩折射,折射按 Snell 定律逐像素求解)
- 测量用**使用参数**(标定结果或厂家标称值 + 设置里的扰动)
- 标定显式建模折射(玻璃距离为机械参数固定取规格值,水折射率取 1.333),主点固定传感器中心
- 体长按「平均深度 × 左图张角」计算(含各像素射线原点偏移),避免独立三角化把深度噪声放大进体长
- 仿真鱼真实叉长已知,测量记录自动对账

## 精度验证

`test/accuracy.ts` 为端到端精度测试(12 组棋盘格标定 + 300 条随机鱼测量):

```
标定后测量:      平均误差 ~1.3%(目标 <2%)
未标定(标称值):  平均误差 ~1.3%(标称值接近真值时)
基线扰动 +5%:    平均误差 ~4.4%(误差如实放大)
焦距扰动 +5%:    平均误差 ~1.2%(体长=基线×视差角,焦距在一阶上抵消,物理正确)
```

运行方式:

```bash
npx tsc test/accuracy.ts --outDir test-out --rootDir . --module commonjs --target es2020 --moduleResolution node --skipLibCheck --strict false
echo '{"type":"commonjs"}' > test-out/package.json
node test-out/test/accuracy.js
```

## 目录结构

```
src/
  core/     数学库(向量/矩阵/LM 求解)、相机模型(针孔+畸变+折射)
  calib/    棋盘格采集仿真、张正友标定 + 联合平差
  render/   WebGPU 渲染器(实例化鱼群、网衣、雾效、畸变后处理)
  sim/      鱼群行为、水下环境
  measure/  有效参数合成、NCC 极线匹配、体长测量、自动测量
  pages/    六个页面
  db/       IndexedDB 数据层
```
